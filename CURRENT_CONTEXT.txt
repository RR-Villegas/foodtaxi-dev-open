Major database changes made
- Added public.product_variant:
  - variant_id uuid primary key
  - product_id uuid references product(product_id) on delete cascade
  - size_label text
  - price numeric
  - stock_quantity integer
  - is_active boolean
  - created_at timestamp
- Added public.order_items.product_variant_id uuid references product_variant(variant_id).
- Added public.account.profile_image_url text.
- Added public.notification:
  - notification_id uuid primary key
  - account_id uuid references account(account_id) on delete cascade
  - notification_type text default System
  - title text
  - body text
  - is_read boolean
  - created_at timestamp
- notification_type check values:
  - System
  - Commerce
  - Delivery
  - Account
  - Promotion
- Added orders money/process columns:
  - service_fee
  - admin_commission
  - rider_fee
  - seller_payout
  - proof_of_delivery_url
  - delivered_at
- Added app_private.decrement_order_item_stock() trigger function.
  - BEFORE INSERT on public.order_items.
  - If product_variant_id is present, decrements product_variant.stock_quantity by quantity.
  - If no variant, decrements product.stock_quantity by quantity.
  - Raises insufficient stock error if stock is too low.
  - Variant branch updates new.product_id from the selected variant's product_id.
- Added/adjusted RLS policies:

  - Admins can update accounts.
  - Admins can update seller/rider applications.
  - Admins can view all orders/order_items.
  - Sellers can update their own order status.
  - Product variant public read and store owner manage.
- User-scoped notification select/update.
- Notification index added on account_id, notification_type, created_at desc.
